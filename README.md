# What a Color Plate Can Tell Us

A source-backed, interactive field guide by RN Collins. The public experience distinguishes a personal appointment from general evidence and each visual test from the others. The screen interactions are conceptual, not clinical instruments.

Run `npm install && npm run dev`; build with `npm run build`. The static `dist/` output is deployed on Vercel. Public questions use a GitHub issue template, require sign-in, and are reviewed manually. The site does not collect visitor health information.
